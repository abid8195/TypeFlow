# TypeFlow

Offline-first typing speed test and practice app.

- Subdomain: `typeflow.freeappstore.online`
- Dev: `pnpm install && pnpm dev`
- Build: `pnpm build`
- Deploy: `git push origin main` (auto-deploys via Cloudflare Pages)

Free, MIT-licensed, no tracking. See
https://freeappstore.online/skills.md for platform conventions.
